## Reinicorn

The map and its decision tickets live on GitHub; the kb's pointer to them
is the branch's plan doc. Record the map issue URL and each decision
ticket's URL there:

```bash
rcorn plan status          # is there a plan doc for this branch?
rcorn plan create          # if not, create one
```

Add the links to the plan and `rcorn kb publish`, so the plan doc stays the
one place that says which map this branch is working.
